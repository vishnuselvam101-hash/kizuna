# ロールと権限

ユーザーには 1 つのロールが割り当てられます。権限の判定はサーバーが行い、画面は使えない機能を表示しないだけです。
許可されていない操作はすべて拒否されます。

| できること | 管理者 | レビュアー | アナリスト | 監査担当 | 閲覧者 |
|---|:-:|:-:|:-:|:-:|:-:|
| 文書・クレーム・判断の閲覧、判断レポートのダウンロード | ✓ | ✓ | ✓ | ✓ | ✓ |
| 文書のアップロード、クレームの抽出・再抽出、「検証を実行」 | ✓ | ✓ | ✓ | | |
| 矛盾のレビュー、識別子ペアの判定、判断の再確認・取消 ¹ | ✓ | ✓ | | | |
| 判断の記録 | ✓ | ✓ | | | |
| ユーザーとセッションの閲覧 | ✓ | | | ✓ | |
| 監査証跡の閲覧、ハッシュチェーンの検証、組織監査レポートの作成 | ✓ | | | ✓ | |
| 「セキュリティ監視」の閲覧 | ✓ | | | ✓ | |
| ユーザー管理、取込設定、AI 支援抽出、検知しきい値の変更 ¹ | ✓ | | | | |
| インシデント対応の承認・却下、隔離文書の解除 ¹ | ✓ | | | | |

¹ 認証アプリで確認したセッション（MFA）が必要です。

## 4つの目の原則（ダブルチェック）
KIZUNA では、自分の作業を自分で確認することはできません。
- 自分が手入力したクレーム、または自分がアップロードした文書を出典とする矛盾は、レビューできません。
- 自分が記録した判断は、再確認も取消もできません。
- 自分がアップロードした隔離文書は、解除できません。

これらの制限にかかった場合は、別のレビュアーまたは管理者に依頼してください。

## ロールの変更
管理者がロールを変更したり、アカウントを無効化したりすると、そのユーザーのセッションはすべて即時に終了します。
新しい権限を反映するには、もう一度サインインしてください。最後の有効な管理者は、削除・無効化できません。
