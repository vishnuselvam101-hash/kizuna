# よくある質問

**サインインしたが、一部のボタンが表示されない。**
ロールにその操作の権限がありません（[ロールと権限](02-roles-and-permissions.md)）。「管理」セクションは、利用できない
ロールには表示されません。

**「この操作には認証アプリで確認したセッションが必要です。」と表示される。**
一度サインアウトし、「認証コード」を入力してサインインし直してください。認証アプリをまだ登録していない場合は
[管理](09-admin.md#認証アプリtotpの登録--api-のみ) を参照してください。

**レビュアーなのに「このロールではこの操作はできません。」と表示される。**
4つの目の原則に該当している可能性があります。証拠を自分で提供した、判断を自分で記録した、文書を自分でアップロードした、
のいずれかです。別の担当者に依頼してください。

**無害な PDF なのに隔離された。**
多くの PDF は圧縮オブジェクトストリーム（`/ObjStm`）を含んでおり、KIZUNA は安全側に倒して隔離します。アップロード者
以外の管理者が解除できます（API のみ）。[文書のアップロード](03-uploading-documents.md) を参照してください。

**「受理」は文書の内容が正しいという意味か。**
いいえ。スキャンを通過したという意味です。同様に、「検証」は保存バイトが変わっていないことを示すだけです。

**信頼度 90% は、値が 90% の確率で正しいという意味か。**
いいえ。信頼度は抽出方法の確からしさであり、値の正しさではありません。

**似た部品番号が統合されないのはなぜか。**
KIZUNA が識別子を自動で統合することはありません。「重複の可能性がある識別子」でレビュアーが判定します。

**「証拠を却下」が「faulty_claims_required」で失敗する。**
現バージョンの既知の制限です。API を使ってください（[矛盾とレビュー](06-conflicts-and-review.md)）。

**判断に使うクレーム ID はどこで確認するか。**
現時点では画面に表示されません。API で確認してください（[証拠と出典の位置](04-evidence-and-sources.md#クレーム-id)）。

**判断が「影響の可能性」になった。どうすればよいか。**
依拠していた証拠が変化しています。「影響を受ける判断」を開いて変化を確認し、再確認するか取り消してください。
記録者本人ではなく、別のレビュアーが対応する必要があります。

**取り消した判断を元に戻せるか。**
いいえ。取消は確定的です。必要であれば新しい判断を記録してください。

**取込設定を変えたのに結果が変わらない。**
設定は次回の抽出から適用されます。理由を入力して「再抽出」してください。

**AI が何かを判断するのか。**
いいえ。AI は、未知のラベルがどの項目に当たるかを提案するだけです。AI によるクレームは、レビュアーが承認するまで
未レビューのままで、判断の根拠にはなりません。

**登録したセキュリティキーで Web 画面にサインインできるか。**
まだできません。Web のサインイン画面は、パスワードと認証コードのみに対応しています。

**通知はメールで届くか。**
インシデントの通知はアプリ内のみです。バックアップ失敗などのサーバー障害については、運用者がメールや Telegram の
アラートを設定できます。

**タブを閉じたらサインアウトされた。**
仕様どおりです。セッションはメモリ上にのみ保持されます。
