# 部品・サプライヤーの照合

文書によって、同じ部品やサプライヤーが異なる表記で書かれていることがよくあります（`KZ-1001` と `KZ1001`、
リビジョンを含む `KZ-1001-B` など）。KIZUNA はこうした組み合わせを検出しますが、**自動で統合することはありません**。
同一かどうかはレビュアーが判断します。

画面：「証拠」›「サプライヤー・部品」の「重複の可能性がある識別子」

## 識別子ペアを判定する
1. 「レコード種別」（部品またはサプライヤー）を選びます。
2. 各行に「識別子 A」「識別子 B」「評価」「検出理由」が表示されます。
   - 評価：「一致の可能性」「要レビュー（曖昧）」「一致」「不一致」
   - 検出理由：「区切り文字の違い」「識別子にリビジョン接尾辞」「1文字の違い」
3. 「同一部品」／「同一サプライヤー」、または「別部品」／「別サプライヤー」を選択します。

対象：MFA 済みセッションの管理者またはレビュアー。判定は監査証跡に記録されます。

## 判定後の動き
- **同一**：識別子が 1 つのレコードとして紐付けられ、両方のクレームを比較できるようになります。
- **別**：そのペアは判定済みとなり、一覧から外れます。
- 「この識別子は既に別のレコードに紐付いています。」と表示された場合は、既存の紐付けを先に確認してください。
- 紐付けた後は、「矛盾レビュー」で「検証を実行」し、新しい組み合わせで比較し直してください。
