# 判断と影響を受ける判断の見直し

判断とは、結果（サプライヤー部品リリースなど）を、依拠したクレームとともに記録したものです。KIZUNA は判断時点の証拠を
スナップショットとして保存し、後から証拠が変わるとその判断に印を付けます。

## 判断を記録する
対象：管理者、レビュアー　画面：「判断」›「判断トレース」の「判断を記録」
1. 「件名」、「部品」（部品の識別子）、「判断種別」（サプライヤー部品リリース、初品承認、逸脱の受入れ、その他）、
   「結果」（承認、却下、条件付き）を入力します。
2. 「根拠」を記入します。
3. 「証拠クレームID」をスペースまたはカンマ区切りで入力します（[証拠 › クレーム ID](04-evidence-and-sources.md#クレーム-id) 参照）。
4. 「判断を記録」を選択します。

証拠がない場合、存在しないクレーム ID を含む場合、却下・置換済みのクレームや未レビューの AI 提案を引用した場合は、
サーバーが記録を拒否します。

## 判断トレースを読む
一覧から判断を選択します。
- 「導出ハッシュ」：判断とその証拠全体に対するハッシュです。
- 「証拠トレース」：判断に関わる証拠のグラフです。変化した項目は強調表示されます。
- 「判断時と現在の証拠」：各クレームの「判断時」と「現在」の値、および「変化」の有無。
- 「判断後の変化」：変化ごとの原因（「クレーム置換」「クレーム却下」「上流の判断」）と、「重要」か「軽微」か。

状態：「有効」「影響の可能性」「置換済み」「取消済み」

## 影響を受ける判断を見直す
画面：「判断」›「影響を受ける判断」。判断後に証拠が変化した判断が一覧表示されます。どの判断も、再確認するか
取り消す必要があります。

対象：MFA 済みセッションの管理者またはレビュアーで、その判断の記録者ではない人
1. 判断を開き、「判断後の変化」を確認します。
2. 「理由」を入力します（必須、2,000 文字以内）。
3. 次のいずれかを選択します。
   - 「最新の証拠で再確認」：現在の証拠に基づく新しい版を記録します。旧版は「置換済み」になります。
   - 「取り消す…」→「判断を取り消す」：取消は確定的で、元に戻せません。

「有効」な判断も取り消せます。「置換済み」または「取消済み」の判断は変更できません。
