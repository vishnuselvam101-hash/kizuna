# KIZUNA Verify 利用マニュアル

KIZUNA Verify は、サプライヤー部品の判断の拠り所となる文書を集め、出典の位置まで特定してクレームを抽出し、
矛盾を検出して人によるレビューに回します。誰が・どの証拠に基づいて・何を判断したかは、改ざんを検知できる形で
記録されます。証拠が後から変わった場合は、再確認が必要な判断を知らせます。

本マニュアルは現行ビルド（main `c9d58a4`）を対象としています。本番運用向けではありません。合成データ、または利用が
承認されたデータのみを使用してください。英語版：[../en/README.md](../en/README.md)
