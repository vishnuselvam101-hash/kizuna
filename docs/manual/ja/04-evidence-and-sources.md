# 証拠と出典の位置

画面：「証拠」›「サプライヤー・部品」

## レコードを開く
1. 「レコード種別」で「部品」または「サプライヤー」を選びます。
2. 「識別子で絞り込み」に入力し、レコードを選択します。「さらにレコードを読み込む」で続きを表示できます。
3. 「{識別子} の証拠」に現行のクレームが一覧表示されます。

## 証拠表の見方
| 列 | 内容 |
|---|---|
| 「属性」 | クレームの対象（寸法、材質など）。 |
| 「値」 | 単位付きの値。 |
| 「リビジョン」 | 値が属する文書のリビジョン。 |
| 「出典」 | 文書名と正確な位置。手で入力したものは「手入力」。 |
| 「方法／信頼度」 | 抽出方法と、その方法の信頼度。 |
| 「レビュー」 | 「未レビュー」「承認済み」「却下」「証拠待ち」のいずれか。 |

- 位置は `page 3`（ページ）、`sheet Spec, cell B7`（シート・セル）、`row 12, col 4`（行・列）、`line 40`（行番号）
  のように表示されます。「位置情報なし」は、抽出処理が位置を特定できなかったことを示します。
- 「出典間で不一致」は、同じ属性の現行クレーム同士で値が食い違っていることを示します。「置換済み {n}件」は、
  置き換えられた旧版の件数です。
- **信頼度は抽出方法の確からしさを示すもので、値が正しい確率ではありません。** CSV・XLSX からの抽出は 90%、
  PDF・DXF は 80% です。AI による提案は最大 70% に抑えられます。

## クレームのレビュー
クレームのレビュー状態は、矛盾のレビューを通じて変わります（[6 章](06-conflicts-and-review.md)）。
現バージョンには、クレームを 1 件ずつ承認・却下するボタンはありません（**API のみ**：`POST /api/v1/claims/{id}/review`）。

## クレーム ID
判断の記録にはクレーム ID が必要ですが、現在の証拠表には ID が表示されません。API
（例：`GET /api/v1/evidence/part/{識別子}`）で確認するか、管理者に問い合わせてください。

## リビジョンを比較する
画面：「証拠」›「リビジョン比較」
1. 「レコード種別」を選び、「識別子」「比較元リビジョン」「比較先リビジョン」を入力します。
2. 「比較」を選択します。

属性ごとに「変更」「追加」「削除」「変更なし」が表示されます。「これらのリビジョン間に仕様の差異はありません。」と
表示された場合、両リビジョンのクレームは一致しています。
