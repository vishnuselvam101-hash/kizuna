# はじめに

## サインイン
1. 管理者から案内された KIZUNA のアドレスを開きます。
2. 「組織」（組織 ID。例：`acme`）、「メールアドレス」、「パスワード」を入力します。
3. 「サインイン」を選択します。
4. 認証アプリを登録済みの場合は「認証コード」欄が表示されます。6 桁のコードを入力し、もう一度サインインします。

補足：
- 失敗が続くと「試行回数が多すぎます。1分待って再試行してください。」と表示されます。サインインの失敗を繰り返すと
  アカウントもロックされます。ロックは管理者が解除できます（[管理](09-admin.md) 参照）。
- セッションはメモリ上にのみ保持されます。タブを閉じるとサインアウトされます。
- **30分間操作がないと**セッションは終了し、サインインし直す必要があります。
- 権限の高い操作（ユーザー管理、設定、レビュー、インシデント対応）には、**15分以内**のサインインも必要です。
  それより古い場合は「再度サインインしてください」と表示されます。サインインし直してから操作を繰り返してください。
- サインイン画面は、現時点ではセキュリティキーに対応していません。セキュリティキーを登録済みの場合は
  [管理 › セキュリティキー](09-admin.md#セキュリティキーapi-のみ) を参照してください。
- 一部の操作には、認証アプリで確認したセッション（MFA）が必要です。コードなしでサインインした場合、これらの操作は
  「この操作には認証アプリで確認したセッションが必要です。」というエラーになります。一度サインアウトし、
  コード付きでサインインし直してください。

## 画面の構成
上部バーに 6 つのセクションがあり、それぞれにサブメニューがあります。

| セクション | 画面 |
|---|---|
| 「概要」 | 「概要」 |
| 「証拠」 | 「文書」「サプライヤー・部品」「リビジョン比較」 |
| 「矛盾」 | 「矛盾レビュー」 |
| 「判断」 | 「判断トレース」「影響を受ける判断」 |
| 「レポート」 | 「監査レポート」 |
| 「管理」 | 「ユーザーと権限」「取込設定」「セキュリティ監視」（利用できるロールにのみ表示） |

- **コマンドパレット**：⌘K または Ctrl+K で開きます。画面の移動、言語・テーマの切り替え、サインアウトができます。
- **言語**：「English / 日本語」ボタンで表示言語を切り替えます。文書名やサーバーが記録した説明文は、記録されたまま
  表示されます。
- **テーマ**：ライトとダークを切り替えます。
- **表の操作**：「行を絞り込み」に入力して絞り込みます。J / K または矢印キーで移動し、Enter で開きます。
  見出しをクリックすると並べ替えます。

## 「概要」画面
- **主要指標**：文書数（うち未受理の件数）、未解決の矛盾（うち証拠待ちの件数）、有効な判断、影響の可能性がある判断、
  監査チェーンの状態（検証権限のあるロールのみ）。
- **証拠グラフ**：文書 → クレーム → 部品・サプライヤー → 判断・矛盾 のつながりを表示します。ノードを選択すると
  その項目を開きます。データが多い場合は先頭のクレームのみ表示します。
- 「レビューが必要な矛盾」と「再検討が必要な判断」から、対応する画面へ移動できます。

## 基本的な流れ
1. 文書をアップロードし、クレームを抽出する（[3 章](03-uploading-documents.md)）
2. 部品・サプライヤーごとに証拠を確認する（[4 章](04-evidence-and-sources.md)）
3. 「検証を実行」し、矛盾をレビューする（[6 章](06-conflicts-and-review.md)）
4. 証拠に基づいて判断を記録する（[7 章](07-decisions.md)）
5. レポートを作成し、監査チェーンを検証する（[8 章](08-reports-and-audit.md)）
