Scope: main `0758242`, read-only (files read with `git show 0758242:<path>`). Covers the sandbox, cryptography, supply
chain and the ASVS 5.0 L2 control-to-test mapping. Nothing was built. Tools run: `cargo audit` on `Cargo.lock` (461
crates, 1,409 advisories: 0 vulnerabilities, 0 warnings, one documented ignore) and `pnpm audit` in `web/` (0 known
vulnerabilities). `pip-audit` was not run (it needs uv and network). `pypdf==6.21.4` is pinned, with hashes in `uv.lock`.

## Verified OK (no finding)

- **bwrap argv**: `--unshare-all --unshare-user --disable-userns --die-with-parent --new-session --clearenv --cap-drop ALL`; read-only `/usr`, ld.so.cache, venv and source binds only; no `--bind`; tmpfs `/tmp` plus `RLIMIT_FSIZE=0`, set by both prlimit and the worker; prlimit applied inside the sandbox with soft and hard limits; `--cpu` equal to the wall timeout; `--nofile=64`, `--core=0`.
- **Process hygiene**: the parent calls `env_clear()`, and Rust fds are CLOEXEC, so only fd 3 (the seccomp pipe) is mapped. Stderr is discarded and stdout is capped at 16 MiB. The process is killed on timeout or drop, and the sandbox fails closed when bwrap or seccomp is unavailable. The `none` sandbox requires `KIZUNA_DEV=1`. Tesseract runs with a fixed argv and environment, no shell, and a timeout. XLSX reading enforces member, total and ratio caps and refuses DTDs. No host-side tmp files: storage uses `create_new` + 0600 + rename, so no symlink race.
- **Argon2id** m=19456, t=2, p=1 (OWASP floor), with a dummy hash for unknown users and hashing on a blocking pool behind a semaphore.
- **TOTP**: RFC 6238 SHA-1, 30 s step, ±1 window, constant-time compare. Replay is blocked by `totp_last_step`, which is re-checked atomically in `complete_login`. The secret is 160-bit and AES-GCM-sealed with AAD binding tenant and user.
- **WebAuthn**: the origin must match the RP ID (config test). `start_passkey_*` requires UV. Challenges are sealed, single use (`DELETE … RETURNING`), user-bound and expire after 5 min. The credential is re-checked after finish and the counter updated. Enrolment revokes existing sessions. Attestation is not enforced (documented).
- **Tokens**: 256-bit random, only SHA-256 hashes are stored, typed prefixes, length-checked parse. Refresh rotation uses `FOR UPDATE`; reuse revokes the session family and is audited. Access tokens are capped at session expiry. The web client keeps tokens in memory only.
- **Data-key AEAD**: AES-256-GCM with a random 96-bit nonce (safe well below 2^32 seals per key). The versioned header is inside the AAD. AAD binds purpose‖tenant‖user‖row for TOTP and WebAuthn credentials and challenges. Rotation goes through the CLI.
- **Hash chain**: `SHA-256(encode(ev) ‖ prev)` with a magic `KZA1`, fixed-width ids, u64 length prefixes and option tags, which makes the encoding injective. Canonical JSON uses sorted keys and integers only, with NUL refused. Length extension is irrelevant because the hash is unkeyed. The checkpoint message (`KZCP1‖tenant‖seq‖len‖head‖signed_at`) is domain-separated from the chain hash. The table is append-only (triggers + grants), with RLS FORCE.
- **Constant-time**: no `==` on secrets. Token and recovery lookups are hash equality in SQL on high-entropy values.
- **Supply chain**: `Cargo.lock`, `uv.lock` (hashed) and `pnpm-lock.yaml` are committed and installed frozen/locked. No `curl | sh` in scripts or deploy. CI has `contents: read` and `cargo-audit` is pinned (`--locked --version 0.22.1`). The `RUSTSEC-2023-0071` ignore is justified (rsa is not compiled). `webauthn-rs`, `seccompiler`, `command-fds`, `pypdf`, `ed25519-dalek` and `aes-gcm` are actively maintained with no open advisories.
- **ASVS mapping**: all of the roughly 55 test names cited in `asvs-mapping.md` exist at `0758242` (0 missing). Six were spot-checked (`tokens_are_stored_hashed`, `health_and_security_headers`, `rls_isolates_at_sql_level_for_runtime_role`, `login_rate_limited_per_ip`, `privileged_needs_mfa`, `signed_checkpoints_detect_full_rechain_by_db_owner`), and each asserts its control. The last one does not cover re-signing after a re-chain (KZ-C1).
